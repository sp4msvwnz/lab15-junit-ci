# Lab 15 — JUnit and Continuous Integration

## Team Members
- Diego Martinez Parra

## Overview
This project demonstrates unit testing in Java using JUnit 5 and Continuous Integration with GitHub Actions.

## Implementation
The `Main` class implements the `hypothenuse(double a, double b)` method using the Pythagorean theorem.

The `MainTest` class verifies the expected result using JUnit 5.

## Testing
Run the following command to execute the tests:

`mvn clean test`

## Continuous Integration
GitHub Actions automatically builds and tests the project whenever changes are pushed to the repository.

GitHub Actions automatically verifies this project after each push.
